# 附录 A：CIP-Dating 数据集构建流程

本附录详细描述书画-题跋成对数据集 CIP-Dating 的构建流程，包括数据来源、采集、题跋识别与校订、年代标注、质量保证与数据划分。

## A.1 数据来源

CIP-Dating 的画面图像来源于公开馆藏书画数字资源，主要包括故宫博物院数字文物库、台北故宫博物院 Open Data 平台以及其他已公开的馆藏书画图像库。题跋文本来源于相应著录文献，包括《中国古代书画图目》《故宫书画图录》等公开著录，以及部分馆藏在线的著录信息。所有数据均来自公开渠道，不涉及未公开的私人藏品。

## A.2 采集与对齐

对每幅书画作品，采集其完整画面图像，并从著录文献中提取对应的题跋文本。题跋文本经光学字符识别初步转写后，由具有书画鉴定背景的标注人员进行人工校订，纠正识别错误并补全异体字、避讳字与干支纪年的规范化转写。校订后的题跋文本与画面图像按作品一一对齐，形成书画-题跋成对样本。

## A.3 年代标注

每幅作品标注两类年代信息。其一为连续创作年代，取著录中给出的创作年代区间的中点，作为连续年代回归的监督标签，取值范围为公元 618 年至 1949 年，近现代的年代上界取 1949 年以覆盖民国时期的书画创作。其二为朝代类别，覆盖唐、五代、宋、元、明、清、近现代共 7 个朝代，各朝代的年代区间依次为 618–907、907–960、960–1279、1279–1368、1368–1644、1644–1912、1912–1949。年代标注以权威著录为准，存疑作品的年代区间在数据集中予以保留，并在训练时以不确定性形式体现。

## A.4 规模与统计

CIP-Dating 共收录 3,214 幅传统书画作品。各朝代样本数分别为：唐 218 幅、五代 156 幅、宋 402 幅、元 287 幅、明 923 幅、清 968 幅、近现代 260 幅。各朝代的样本分布存在一定程度的长尾，其中明清两代作品合计占比近六成，唐、五代作品相对稀缺，这与现存书画的客观分布一致。题跋平均长度约 42 字，其中可提取出至少一条时间锚点的作品占 84.6%，平均每幅作品提取出 2.3 条时间锚点。

每幅作品除画面、题跋与年代标注之外，还记录其作者与馆藏来源两项元数据，用于划分时的分组。数据集按 7:1.5:1.5 的比例划分为训练集、验证集与测试集，划分以作者与馆藏来源为分组单位：同一作者的全部作品、以及来自同一馆藏且经人工核定为同一批入藏的作品，整体划入同一个子集，不跨子集分布。在同源作品内部再按朝代分层，以保持各子集的朝代分布一致，并固定随机种子以确保可复现。这一分组划分的目的是避免同源泄漏：若同一作者的近似图像或同一批入藏的作品同时出现在训练集与测试集，模型可能学到馆藏来源或作者个人的用笔习惯等与年代无关的特征，从而高估其年代辨识能力。作为对照，本文同时报告按朝代分层随机划分的结果，两种划分的差异见表 14。完整的数据划分清单随数据集一并发布，其中列出每个子集的样本编号、作者与馆藏来源。

## A.5 质量保证

为保证标注质量，题跋校订采用双人独立标注与仲裁机制：两位标注人员独立校订同一题跋，不一致处由第三位资深鉴定人员仲裁。参与标注的人员共四位，均具有书画鉴定或古文字专业背景，标注前统一接受异体字、避讳字与干支纪年规范化规则的培训。为量化标注的可靠性，本文在正式标注前抽取 300 幅作品进行双人独立标注的一致性评估：题跋校订的一致率为 94.2%，Cohen's $\kappa = 0.91$；时间实体类别标注的一致率为 91.6%，$\kappa = 0.87$；年代标注在允许 ±10 年容差下的一致率为 89.3%，$\kappa = 0.85$。三者的 $\kappa$ 值均落在"几乎完全一致"一档，说明标注规则明确且可复现。

年代标注以权威著录为唯一依据，凡著录间存在显著年代分歧的作品，标记为存疑样本并在消融与鲁棒性分析中单独考察。存疑样本的具体处理方式是在训练时保留其年代区间而不强行给出点标签，在评测时单独统计其误差与自洽度，而不计入主表。需要指出的是，本文的年代标注来自著录而非独立的实物测定，著录本身的学术争议无法通过标注流程消除，这一点在 6.4 节作为局限之一列出。

## A.6 使用规范

CIP-Dating 面向学术研究开放，使用时应遵循原始馆藏与著录的版权与使用规范。数据集仅用于年代辨识及相关算法研究，不得用于商业用途。
