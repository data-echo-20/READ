# 附录 B：复现性清单

本清单列出复现本文实验所需的全部环境、超参数、数据与代码信息，供研究者核对。

## B.1 软件与硬件环境

- 操作系统：Ubuntu 20.04 / Windows 11
- 编程语言：Python 3.9
- 深度学习框架：PyTorch 2.0
- 视觉编码器：ViT-Base 预训练权重
- 题跋编码器：SikuBERT 古文预训练权重
- 硬件：单块 NVIDIA A100 GPU（40 GB 显存）

## B.2 关键超参数

- 视觉编码器：12 层 Transformer，隐层维度 768，注意力头数 12，图像块尺寸 16×16，输入分辨率 224×224
- 题跋编码器：SikuBERT 隐层维度 768
- 时间网格：年代范围 [618, 1949]，网格点数 L = 200，步长 Δ ≈ 6.69 年
- 软证据输出域：均值 μ_ν 经 sigmoid 映射到 [618, 1949]，标准差 σ_ν 以网格步长 Δ 为下界；二者均为式 (7) 归一化良定义的必要条件，见 3.4 节
- 数值实现：式 (6) 至式 (8) 须在对数域以 logsumexp 完成，且 log ν 直接由式 (3) 的对数形式计算，不得先求密度再取对数；否则锚点与画面严重冲突时会出现零除与非数，见 3.6 节
- 温度系数：ε = 4σ_base² = 3600，画面标称不确定度 σ_base = 30 年；该取值由命题 1 的准则确定，对应信任系数 τ = 1/3
- 锚点宽度下界：σ_min = 1.0 年，由 σ_i = σ_min + softplus(·) 保证。不可设为 0，否则边际化核退回插值约定，归一化保留率的上界语义被破坏
- 核宽与保留率：式 (6) 的核宽为 W_i = ε + 2σ_i²，式 (8) 的归一化保留率闭式见式 (26)；σ_i = 0 时严格退回点锚点形式（χ = 0.8165、α = 2/3、τ = 1/3）
- 自洽度正则间隔：m = 0.25，即冲突样本的目标自洽度不高于 0.75。注意自洽度 SC ∈ (0, 1] 为无量纲量，该间隔无须随年代尺度调整
- 冲突定位容忍量：锚点位置与样本真实年代相差超过 60 年即判为冲突锚点，见 5.12 节
- 优化器：AdamW，初始学习率 1×10⁻⁴，权重衰减 5×10⁻²，批量大小 32
- 学习率调度：5 轮线性预热 + 余弦退火，训练 100 轮，早停耐心 10 轮
- 损失权重：λ_reg = 1.0，λ_cls = 1.0，λ_cons = 0.1，λ_cal = 0.1（式 16）
- 数据增广：15% 概率丢弃题跋（对应 K = 0 的恒等似然退化）、10% 概率以同数据集内跨朝代采样的伪题替换真题（不使用常数年代偏移）

## B.3 数据

- 公开数据集：Mogao（敦煌壁画）、MCCD（书法字符）、HCSU（历史书法风格）、CP-Dynasty（中国画朝代风格）
- 自建数据集：CIP-Dating（3,214 幅书画-题跋成对样本，构建流程见附录 A）
- 数据划分：训练集/验证集/测试集 = 7:1.5:1.5，按作者与馆藏来源分组划分，组内再按朝代分层；同时报告按朝代分层随机划分与留一馆藏来源交叉验证的对照结果，见 5.1 节与 5.12 节表 14
- 数据划分清单：随数据集发布，列出每个子集的样本编号、作者与馆藏来源，供核对分组是否正确

## B.4 训练与评测

- 随机种子：固定 5 个种子（42、137、256、1024、2024），所有实验报告这 5 次独立运行结果的均值与标准差；逐次运行结果见 B.5
- 评价指标：朝代分类准确率、宏平均 F1、加权 Kappa、连续年代平均绝对误差、预测区间覆盖率、负对数似然、CRPS、期望校准误差、Brier 分数、自洽度 AUC、伪题跋检测 AUROC/AUPRC/FPR@95TPR、锚点级冲突定位准确率与 P/R/F1
- 样本级统计检验（统计单元为测试样本，在固定测试集上完成）：连续年代误差采用配对 Wilcoxon 符号秩检验与 10,000 次重采样的配对自助法 95% 置信区间；朝代分类准确率采用逐样本 McNemar 检验
- 运行级统计检验（统计单元为随机种子）：报告 5 个种子的均值与标准差，并给出配对 t 检验（df = 4）与配对设计效应量 d = t/√n。该检验衡量的是训练过程的随机性，不反映测试集自身的抽样噪声，不可作为对测试集样本显著性的依据
- 多重比较：同一指标上的多基线比较施加 Holm 校正，同时给出原始 p 值
- 伪题跋检测的评测协议：正例为画面与真实题跋配对，负例为画面与同批次内跨朝代题跋配对（与训练增广的构造方式一致）
- 锚点级冲突定位的评测协议：向伪题样本中注入一条年代错位的锚点，以式 (9) 的冲突分数 d_i 最大者为预测结果，随机猜测基线为 1/K；锚点级的 P/R/F1 以冲突分数的 80 分位为判定阈值
- 概率校准的评测协议：以朝代分类头最大类概率为置信度、预测是否正确为标签计算 ECE 与 Brier；预测区间覆盖率由网格后验的阶梯 CDF 分位点给出；CRPS 取离散预测分布的能量形式
- 标签来源声明：自洽度正则项的标签由受控增广构造（15% 丢弃题跋、10% 跨朝代替换），仅在训练集内生成，测试集不参与任何标签构造；时间实体抽取使用冻结的编码器与公开著录词表，不接触测试集统计信息；连续年代标签取著录所载创作年代区间的中点

## B.7 复现步骤

1. 下载公开数据集与 CIP-Dating，按 B.3 的分组协议与发布的划分清单划分。
2. 安装 B.1 所列软件环境与依赖。
3. 运行 code/ 目录下的训练脚本，加载 ViT-Base 与 SikuBERT 预训练权重。

5. 运行评测脚本，输出表 2 至表 14 的全部指标与 B.5 的逐次运行结果。
6. 运行 figures/gen_figures.py 复现图 2 至图 18。
